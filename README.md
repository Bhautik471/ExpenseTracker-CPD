# Expense Tracker – Cross Platform Mobile Application

## Features
- Add expense name, amount, category and date
- Food, Travel, Shopping, Education, Bills and Other categories
- Automatic total amount calculation
- Recent expense list
- Delete expenses
- Local data persistence using AsyncStorage
- Android, iOS and Web through Expo

## Run
1. Install Node.js and Expo.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npx expo start`
5. Scan the QR code with Expo Go, or press `a` for Android.

# Expense Tracker – Cross Platform Mobile Application

## Introduction
Expense Tracker is a cross-platform mobile application developed using React Native and Expo. It helps users manage daily expenses by adding expense records, selecting categories, and viewing total spending.

## Features
- Add expense name, amount, category and date
- Food, Travel, Shopping, Education, Bills and Other categories
- Automatic total amount calculation
- Recent expense list
- Delete expenses
- Local data persistence using AsyncStorage
- Android, iOS and Web support through Expo
